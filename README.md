# ChromaMCP

> **Status: specification only.** This repository contains no implementation yet. It is
> a stated direction, not working software.

An MCP server intended to give AI clients chromatographic domain tools — so that a
question about a method, a system, or a procedure resolves against a named clause rather
than a plausible-sounding paragraph.

## Intended scope

| Area | Governing documents |
| --- | --- |
| System suitability | USP `<621>` |
| Analytical instrument qualification | USP `<1058>` |
| Analytical procedure validation | ICH Q2(R2) |
| Analytical procedure development and lifecycle | ICH Q14 |

## What it is not

- Not an instrument control layer.
- Not a validated system, and no claim of fitness for a regulated decision.
- Not a substitute for a qualified person's judgement, the laboratory's own SOPs, or
  the current text of the standards it references.

Regulatory interpretation depends on the controlled copy of the text and on a qualified
reviewer. Tooling can make the reasoning traceable; it cannot make the decision.
